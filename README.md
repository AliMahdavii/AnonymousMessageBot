# 💬 Anonymous Message Bot

A simple and lightweight Telegram bot for sending and receiving anonymous messages through personal links.

🤖 Bot
[Open Anonymous Message Bot on Telegram](https://t.me/AliAnonymousMessageBot)

## ✨ Features

- 🔗 Personal message links
- 💬 Anonymous messages
- ↩️ Anonymous replies
- 🌐 Persian & English language support
- 🗄️ SQLite database
- ☰ Telegram Bot Menu
- 🧹 Simple message management
- 🔒 Sender identity hidden from recipients

## 🛠️ Tech Stack

- Python
- pyTelegramBotAPI
- SQLite
- python-dotenv
- Telegram Bot API
- Git & GitHub

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/AliMahdavii/AnonymousMessageBot.git
cd AnonymousMessageBot
```

## 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it:

Windows

```bash
venv\Scripts\activate
```

## 3. Install dependencies

```bash
pip install -r requirements.txt
```

## 4. Configure environment variables

Create a .env file:

```bash
BOT_TOKEN=your_telegram_bot_token
```

## 5. Run the bot

```bash
python main.py
```
